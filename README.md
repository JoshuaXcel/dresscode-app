# FUTASU Judicial Council: Swearing-In Dress Code

The official swearing-in dress-code guide for the FUTA Students' Union Judicial Council, 2026/27 Parliamentary Session.

Live site: https://joshuaxcel.github.io/dresscode-app/

## What's inside

- Men's and women's tabs: accepted English attire, native attire and footwear, with photo examples
- Not permitted list and additional notes
- About, FAQs and a WhatsApp contact for the EDC Chairperson

## Files

```
index.html   page content
style.css    styles
script.js    tabs, FAQ accordion, back-to-top button
images/      outfit photos, logo, favicon and link-preview image
```

Plain HTML, CSS and JavaScript, hosted on GitHub Pages. No build step: edit and push.

## Adding a photo

Resize it to about 1000px on the long side and save as JPEG (quality ~78) so the page stays fast on mobile data, put it in `images/`, and reference it as `images/your-photo.jpg` with `width`, `height`, `alt` and `loading="lazy"`.
